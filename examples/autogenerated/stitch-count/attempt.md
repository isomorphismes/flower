## Type-system sketch

chain ID have different roles even if both are represented by bounded whole
numbers. An increase means a second child attached to a particular parent;
it is not a scale factor applied to existing material.

The small pure operation has signature
`count_after_explicit_increases : Number → Number → Number`.
Its first input counts existing parents, its second counts additional children;
its result is their sum. The complete boundary would use `stitch_ledger`,
`material_stitch_id`, `foundation_chain_id` and `round_instructions` instead of
unrestricted numbers. Invalid parents, duplicate IDs, seam mistakes and counted
lifting chains must fail before output.
